# Game3R

A simple static frontend for a games deals listing site built for the HNDIT2062 ICT Project.

Contents
- `home.html` — Main landing page
- `login.html` — Simple login page (dummy credentials: `hi` / `1234`)
- `style.css` — Styling for the site
- `img/` — Game images and assets

How to run locally
1. Open the project folder in any static file server or VS Code Live Server extension.
2. Open `login.html` in a browser and use the dummy credentials to navigate to the site.

License

Notes
- This is a static prototype. No backend.
- Remove or change the dummy credentials before production use.
